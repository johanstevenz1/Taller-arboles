- Use Python 3.10+, FastAPI, and a functional HTML/CSS/JavaScript frontend.
- Implement Node and the AVL tree from scratch; never use tree libraries.
- Keep code, identifiers, filenames, comments, docstrings, endpoints, and commits in English.
- Keep all visible application text in Spanish in frontend/js/messages.js.
- Provide public Python functions with type hints and English docstrings.
- Document operation time complexity in tree docstrings and the README.
- Provide insertion, deletion, search, preorder, inorder, postorder, BFS, size, height, and JSON serialization.
- Separate models, services, routes, rendering, API calls, and UI messages.
- Use domain exceptions and test errors, empty trees, rotations, deletion shapes, and invariants.
- Use pytest and exceed 80% coverage of tree logic.
- Verify the full frontend flow and include actual screenshots.
- Never commit credentials, personal records, environments, or runtime files.
- Use English Conventional Commits and publish to main in the user-specified repository.
- Honor the user-specified repository name despite the assignment's naming recommendation.
